# 技术面试题库（点击展开答案）

## 怎么用

1. 用浏览器打开 `index.html`（双击或 Cursor 里 Open with Live Server / 简单静态服务均可）。
2. 左侧选分类，或顶部搜索关键词、题号（如 `llm-003`、`GIL`）。
3. **先自己想**，再点击题干展开答案。
4. 可标记「已掌握 / 稍后复习」（存在本机浏览器）。
5. 「复制题号」后发给我，方便深挖回填。

## 深挖同步约定（你提的需求）

你之后会对某题反复追问。流程固定为：

1. 你说题号，例如：`继续深挖 py-003，事件循环取消 Task 怎么做？`
2. 我在对话里详细解答。
3. **同步**：把补充要点写回 `data.js` 里该题的 `answerHtml`，并更新：
   - `answerText`（便于搜索）
   - `updatedAt: "YYYY-MM-DD"`（页面答案底部会显示「已深挖更新」）

这样题库会随你的提问变厚，而不是散落在聊天记录里。

## 当前覆盖

| 分类 | 内容方向 |
|------|----------|
| 底层 | 进程线程、虚拟内存、用户态内核态、TCP/HTTP、IO 多路复用、锁 |
| Python | GIL、多线程/进程、asyncio、装饰器、GC、FastAPI 路由 |
| MySQL | B+Tree、联合索引、事务隔离、慢 SQL、锁 |
| Redis | 单线程模型、类型、持久化、缓存三连、分布式锁 |
| ES | 倒排、分片、mapping、近实时 |
| Mongo | 场景选型、嵌入引用、副本分片 |
| 向量/知识库 | ANN、库选型、切分、混合检索、知识库形态 |
| 接口设计 | 好 API、幂等、分页、契约、限流熔断 |
| 中间件 | Kafka、ZK、Nginx、扩展清单 |
| 大模型 | RAG、Agent、MCP、Tool/Skill 关系、幻觉、流式、长文本、记忆、沙箱、评测、注入 |

深度标注：`基` / `中` / `深`。底层与大模型偏「深」题更多。
